# Agent Skills — CyberRadar

## Data and API audit
Inspect schemas, provenance, source freshness, rate limits and failure behavior. Report exact file paths and reproduction steps.

## Feature implementation
Implement one roadmap item with explicit acceptance criteria and backward-compatibility notes.

## Test and evaluation design
Build deterministic fixtures for valid, missing, contradictory, stale and malformed inputs. For model/evidence quality, define a baseline and labelled evaluation set before reporting metrics.

## Security and privacy review
Check credentials, untrusted content, external API handling, user data and abuse limits.

## Documentation review
Explain the project to a non-expert first, then document data flow, scoring, assumptions and limits for technical reviewers.

Agents cannot autonomously merge, deploy or claim certification. A human maintainer approves high-impact decisions.

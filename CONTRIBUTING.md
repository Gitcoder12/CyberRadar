# Contributing to CyberRadar

1. Read README.md and the feature plan.
2. Check current issues and PRs before duplicating work.
3. Pick a bounded task and state acceptance criteria.
4. Work on a feature branch; do not commit directly to the default branch.
5. Add tests for valid, invalid and failure inputs.
6. Include exact commands, environment, results and limitations in the PR.
7. Append a truthful entry to ACTIVITY_LOG.md.

Do not commit secrets, private data or unlicensed sources. Do not claim tests or benchmark results that were not run. Human maintainers approve merges and deployments.

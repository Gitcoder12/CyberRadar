# CyberRadar — Company and Team Fit

**Snapshot:** 2026-11-13

## Why this project exists

A dashboard that collects public vulnerability records and helps defenders decide which known security issues deserve attention first.

Company names below are potential skills and employer matches only; they are not known users, partners, customers or endorsers.

## Microsoft

**Relevant public areas:** Security research, Defender and vulnerability management.

**Potential role families:** Security Engineer, Data Engineer, Research Engineer, ML Engineer, Applied Scientist or Software Engineer.

**Evidence to demonstrate:** Streamlit application combining NVD CVE records, CISA KEV known-exploited status and FIRST EPSS probability signals into a prioritisation view. Any combined risk score is a project heuristic; it should expose component values, source timestamps, missing data and scoring rules.

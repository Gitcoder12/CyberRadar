# Agent Instructions — CyberRadar

Read README.md, CONTRIBUTING.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md first.

- Inspect code, tests, open PRs and issue history before editing.
- State one bounded objective, expected files, risk and validation plan.
- Work on a dedicated branch and keep diffs reviewable.
- Validate untrusted inputs and preserve provenance/licensing.
- Add tests for normal, boundary, missing and failure cases.
- Run real commands and report exact output; never invent test evidence.
- Update docs and activity log, then open a PR for human review.
- Never merge, deploy, publish a release or access secrets autonomously.

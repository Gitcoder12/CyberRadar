# CyberRadar — README Quality Checklist

## Beginner reader
- [ ] Explains the problem in ordinary language.
- [ ] Provides a real example and exact setup steps.
- [ ] Explains what the user sees and how to interpret it.

## Technical reader
- [ ] Describes architecture, APIs, data sources, schema and scoring logic.
- [ ] Documents timestamps, freshness, errors, uncertainty and provenance.
- [ ] Links tests, benchmark methodology and reproduction steps.
- [ ] Clearly states what the system does not prove or decide.

## Collaborator
- [ ] Links roadmap, activity log, contribution guide and company-fit page.
- [ ] Has small work packages with acceptance tests.
